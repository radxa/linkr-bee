# Agent 任务证据与恢复

## 计划中的完成含义

`update_task_plan` 为每一步记录 `expectedResult`（预期）、`verification`（观察说明）、
`evidenceIds`（工具结果中的 `taskEvidence.id`）及下一步。

- `kind=action` 为默认值。完成它必须引用本次提问中已经返回、并在后续模型轮次读过的
  应用校验结果；结果必须为 `match`，且对应执行已经完成。配件设置也可引用已结束的
  应用回读匹配，但仅覆盖实际比较的 UART 参数或网络开关状态。退出码 0、发送成功、模型
  编写的成功说明、超时、`observed`、`indeterminate` 和 `mismatch` 都不能替代这个条件。
- `kind=observation` 仅表示诊断资料已经收集/观察。界面明确显示“观察已记录，未证明修复
  成功”；不能用它声称操作已经生效。
- 应用核对证据的来源、轮次和校验状态，也拒绝用操作之前的校验来首次完成一个新的
  操作步骤。此前已经接受的完成步骤可以保留其证据；历史证据不能直接完成新提问中的步骤。
- 应用不判断预期是否覆盖用户的全部目标。例如大小符合预期不等于固件型号正确；
  服务进程存在不等于功能正常。证据保留路径/服务、比较条件、执行 ID，供用户核对。
  尚无机器校验的操作应保留受阻/未验证状态，并说明所需的独立检查。

应用校验通过只支持指定条件，不是安全认证。目标机输出本身仍是不可信输入。

## 检查点

任务记录按设备隔离，保存计划、有限的证据索引、历史日志游标和最多 8 条待核实执行引用。
已核实目标机 ID 时按目标 UUID 隔离；未核实时沿用桥接设备与 UART 的降级标识，不能
用这个降级标识证明目标机身份，也不能把历史档案当作当前目标机事实。
引用包括执行器随机实例 ID、连接会话、执行编号和请求 SHA-256 指纹；不保存可供重放的
串口 payload、脚本字段、模型密钥或历史审批。计划文字可能提及命令，但只按普通历史
文本处理；计划文字和证据摘要经过现有脱敏处理。

`get_task_checkpoint` 只读检查恢复点：

1. 同一执行器/连接里仍有该记录：只观察原执行，结果未定时先监控同一 ID；收到完成
   结果后再次检查恢复点，再决定后续操作。
2. 刷新页面或换了连接，原记录不可用：返回 `unavailable / unknown`。新的 `serial-1`
   不能冒充上一页的 `serial-1`，也不能把不可用解释成进程已停止、失败或成功。
3. 恢复前读取当前状态、日志和恢复点，并让这些结果进入下一轮模型上下文。历史日志
   游标只作定位信息，不能直接套到新连接的日志上。
4. 对结果未知的历史请求，应用阻止自动重发相同指纹的输入。允许基于当前控制台状态，
   按原有执行策略检查操作效果。指纹不是命令语义分析，不能识别所有不同写法的等价操作；
   模型仍须遵守“不改写重发、不确定就说明”的规则。

刷新后会从最近任务带入待核实引用；同一对话下一次提问也保留尚未解决的执行。
停止 Agent 只停止观察，不停止目标机进程。没有可用执行记录时，不承诺跨刷新接管进程。
历史检查点不会复用执行权限，新对话也不会自动执行其中的内容。

## 场景评测

单元回归使用真实 Pi 循环和模拟模型，验证证据检查、工具链、恢复引用与评分器；
它不能证明模型在自然语言任务中每次都能选对工具。

查看真实模型评测场景（不请求模型）：

```sh
cd mobile
npm run eval:agent -- --list
```

执行时显式配置 `LINKR_EVAL_ENDPOINT`、`LINKR_EVAL_MODEL`、`LINKR_EVAL_API_KEY`
（无密钥端点可省略 Key）；协议可用 `LINKR_EVAL_PROVIDER` 选择。
然后运行 `npm run eval:agent`。此命令会向指定服务发起真实模型请求，可能产生费用。
不会从浏览器提取现有密钥。串口和文档读取全部是固定模拟对象，不运行本机命令、不连接
真实硬件，也不把真实设备日志发送出去。

6 个固定场景覆盖已有工具缺失记录、文件匹配/不匹配、密码提示、刷新后执行未知、板型
不明确。每场景最多 12 轮、30 次工具调用，90 秒停止；只输出通过情况、计划错误完成、
计划拒绝次数、重复串口请求、工具次数和报告的 token 用量，不输出完整提示和凭据。
重复请求比较会去除随机退出标记，避免把新的退出 token 当成不同操作。

评分器检查工具与计划记录及少量回答特征，不是对全部自然语言承诺的自动事实核查。
真实模型评测和真实设备验收应分别记录，不能用模拟通过率代替实机结果。
