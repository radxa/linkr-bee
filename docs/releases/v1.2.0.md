`{{TAG}}` 是项目发布标签；本次所有组件统一为 `{{FIRMWARE_VERSION}}`：固件（Kconfig 默认值）、Rust CLI/TUI、npm 上的 `linkr-bee-cli`、Web/手机包、Android 调试 APK 的 `versionName`、Python 参考客户端，以及 DeepSeek Harness 插件 `dsh-linkr-bee`。`python3 tools/check_versions.py {{TAG}}` 是这条承诺的可执行版本，CI 会在编译前先跑一次。

### 1.2.0 相对 1.1.5

- **全屏程序不再「只占一角」。** 目标板跑 htop/nvim/mc 时，客户端只在空闲 shell 提示符下发 `stty`；此前 zsh 的 `%`、fish 的 `>`、`buildroot:~#`、`(venv) user@host:~$` 这些提示符一律识别不到，等于**从未同步过**，tty 停在开机默认的 80×24。现在识别 `$ # % >` 四种结尾，且仍要求前缀像提示符（`=> `、`echo hi >`、`100%` 依旧拒绝）。首次同步也不再等 180 ms 去抖。
- **手机端可以给目标板定尺寸。** 原生壳默认每次连接在第一个空闲提示符处同步一次（TUI 启动读到的就是这个值），软键盘开合永远不改远端；「同步目标尺寸」开关打开后持续跟随。该开关只在原生壳出现——桌面浏览器本来就始终同步，留着就是无效控件。
- **BLE 链路提速。** 所有板子主动请求 7.5–15 ms 连接间隔与 2M PHY（此前 `CONFIG_BT_GAP_AUTO_UPDATE_CONN_PARAMS=n` 且从不请求 PHY，实测停在 37.5 ms / 1M）。BT 4.2 的 WROOM 自动保持 1M；C5 与 X1.0 早已配置的 `PREF_TIMEOUT=800` 也因此真正生效。
- **状态灯反映真实状态。** 由连接、WiFi、AI 活动驱动，常驻任务接管时指示绑定到正在运行的任务。
- **C5 缓冲按实测收缩。** 三个缓冲改用测量值而非「剩下多少用多少」，并更正此前对栈与 WebSocket 失败的归因。
- **Harness 插件。** 链路自愈与面板如实上报（`resize` 不再谎报尺寸）、dry run 不再扫描板子、命令配置与保留事件有界、设置页说明与实际保存项一致、能找到 linked checkout 里构建的 `bee-cli`。
- **Web/固件可靠性。** BLE GATT 操作串行化、队列按连接生命周期隔离、并发 HTTP 握手所需的 poll 容量；`?demo=board` 现在会回显 UART 输入（按 cooked tty 的 ONLCR 把 CR 转成 CRLF），因此可以离线演示全屏程序。

### 本次包含

- **一条版本线，可执行校验。** 所有组件的版本号与标签由 `tools/check_versions.py` 统一校验（含 iOS `MARKETING_VERSION`、HarmonyOS、Android `versionName`、`package-lock`），标签缺 `docs/releases/{{TAG}}.md` 也会失败。
- **发布资产白名单。** 裸 `bee-cli-<target>` 作为独立 `cli` 类资产参与发布并被 `linkr-bee-cli` npm 包校验下载；不参与版本推断（文件名本来不带版本）。
- **X1.0 用户手册** 与启动日志排查记录（ROM 下载态不应被误判为固件问题）。

### 已知限制

- 串口没有带外窗口尺寸通道：全屏程序运行期间无法改变目标 tty 尺寸，客户端只在空闲提示符处写 `stty`。手机上软键盘弹出时可视行数会减少（36→21 行），目标 tty 不变——这是有意的，避免把 `stty` 敲进正在运行的程序。
- 固件侧 UART 改参/发送竞态、WiFi 扫描代际、Reliable UART 丢块可观测性、未认证 WebSocket 槽位配额仍需真机复现，本次未改。
- 本地 `tools/linkr-tui/target` 与 `build-*` 目录未清理，均被 `.gitignore` 覆盖。

### 下载选择

- 桌面终端：`linkr-bee-{{FIRMWARE_VERSION}}-<target>.tar.gz` / `.dmg`，命令行面是 `linkr-bee-cli-{{FIRMWARE_VERSION}}-<target>`；只想在 Harness 里用，装 `linkr-bee-cli` npm 包即可。

- Web：`linkr-bee-{{TAG}}-web.zip`；手机端：`linkr-bee-{{TAG}}-android-debug.apk`。
