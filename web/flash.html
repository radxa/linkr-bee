ESP32-CAM 烧录方式（单板 + CH340 USB-TTL）
  1. 拔掉摄像头和 SD 卡。
  2. 按下面的接线表连接 CH340，烧录时把 GPIO0 接到 GND。
  3. 给 CH340 插上 USB，确认电脑出现串口。
  4. 波特率选 115200，点“连接串口并烧录”。烧录完成后断开 GPIO0，再复位运行。
  5. 运行前必须拔掉 CH340 的 USB，CAM 改用独立 5V 供电。CH340 继续插着时，它的 TX 会和目标 TX 抢 GPIO3，表现为 BLE 能连上但串口没有输出。
  • CH340 5V → CAM 5V
  • CH340 GND → CAM GND
  • CH340 TX → CAM U0R（GPIO3）
  • CH340 RX → CAM U0T（GPIO1）
  • CAM GPIO0 → GND（只在下载时短接）

使用稳定的 5V 2A 电源或带供电的 USB HUB，线尽量短。连接失败时确认 GPIO0 已接地并重新上电，再点“已进入下载模式，重试连接”。

把 CAM 当 BLE 串口桥使用时：目标 TX → CAM U0R（GPIO3），目标 RX → CAM U0T（GPIO1），并共地。烧录用的 CH340 必须完全断开。
