Linkr Bee · 固件刷写

正在读取固件清单…

插上板子、选择型号、点一下写入。固件随本站发布，浏览器直接通过 USB 刷写， 不需要安装 esptool 或驱动。

刷写前请确认

  • 桌面版 Chrome 或 Edge：刷写用的是 Web Serial，Safari 与 Firefox 不支持。
  • 用能传数据的 USB 线；只有充电线时电脑看不到串口。
  • Linkr Bee X1.0 与 C3 开发板走芯片自带的 USB-Serial/JTAG，插上就能选； WROOM 开发板需要板载 USB-UART 芯片。
  • 写入的是 0x0 应用区。已保存的配对与设置通常在别的分区里，会保留； 但刷机有风险，重要配置请先备份。
  • 刷完拔插一次 USB，再回到串口终端连接。
